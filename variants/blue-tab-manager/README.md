# Blue Tab Manager · 南瓜公主🎃

这是 Xiaoyu Tab Manager 的独立个性化副本，保留原版标签管理功能。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择本文件所在的 `blue-tab-manager` 文件夹，也就是直接包含 `manifest.json` 的目录。
4. 打开新标签页，确认扩展名称为 `Blue Tab Manager`，问候语包含 `南瓜公主🎃`。

ZIP 版本需要先解压，再选择解压后直接包含 `manifest.json` 的文件夹。

## 本次定制

- 扩展名称、页面标题、工具文案统一为 `Blue Tab Manager`。
- 中英文问候语的固定署名统一为 `南瓜公主🎃`。
- 工具导出文件名使用 `blue-tab-manager` 前缀，地址栏关键词为 `btm`。
- 原有域名、工作、窗口视图及图标、拖拽、精确关闭等功能保持一致。

这是从源码复制出的独立扩展，不包含原版扩展在浏览器里保存的工作归属、主题、会话或其他个人数据。

## 自动复用相同网址（1.1.0）

在新标签页打开「设置 → 标签页 → 自动复用相同网址」，允许通知后开启。功能默认关闭。

先打开一个新的前台标签页，再加载网页。如果同一 Chrome 个人资料的普通窗口已经打开完全相同的 URL，Blue 会切回已有标签，确认成功后只关闭刚开的标签，并发送本地通知。参数值、参数顺序和 `#` 片段都参与比较。

现有标签内的导航和刷新、直接打开链接、后台标签和会话恢复不触发自动关闭。检测从浏览器报告首次加载时开始，不拦截网络请求。目标失效、切换失败、通知权限不可用时，保留新页。网址只在本地内存中比较，不写入通知或日志。
