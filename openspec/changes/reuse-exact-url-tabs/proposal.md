## Why

从新标签打开已经在另一个窗口中的页面，会多出一个副本并丢失原来的阅读位置和页面状态。现有手动查重只能事后整理，无法在打开时复用已有页面。

## What Changes

- 新增默认关闭的“自动复用相同网址”开关。启用后，只检查可确认属于首次加载的前台新标签页。
- 在同一 Chrome 个人资料的普通窗口中，按浏览器提供的完整 HTTP(S) URL 精确比较，保留查询参数、顺序和 `#` 片段，不按域名猜测。
- 命中已有页时先激活该标签和窗口；确认切换成功且新页仍符合条件后，只关闭新页，发送不含网址的结果提醒。
- 增加可选的 `notifications` 权限，用户在开启功能时授权。未授权或权限被撤销时不自动关页。
- 保持手动查重、既有标签导航和会话恢复行为。先在 Blue 副本验证，后续按用户确认移植功能到 Xiaoyu 原版；保留两个版本各自的名称、图标和问候语。

## Capabilities

### New Capabilities

- `exact-url-tab-reuse`：按完整 URL 在新标签首次加载时复用已有标签，并规定提醒、安全关页与失败边界。

### Modified Capabilities

无。

## Impact

- 分阶段接入 `variants/blue-tab-manager/` 与 `extension/` 的后台事件监听、设置界面、本地存储、通知文案和 Manifest；保持现有必需权限，不申请网站访问权限。移植阶段不修改 Blue 文件。
- 在后台使用现有 `tabs` 权限检查 URL，以 `tabId` 激活和关闭标签。不调用可能回退到同域名的旧跳转方法。
- 增加精确比较、首次加载、并发失效、权限与焦点切换的单元测试，以及隔离 Chrome 跨窗口验证；分别生成安装包。
