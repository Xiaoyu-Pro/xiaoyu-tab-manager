## Context

快捷视图已按映射分组，组内按钮显示页面名、网址与打开状态。现有渲染器和 `keyword-search.css` 足以完成本次调整，不需要新组件或存储迁移。

## Goals / Non-Goals

目标：圆角正方形名称块、跨组同名同色、紧凑且易点击，保留既有交互与主题。非目标：修改映射管理列表、顶部搜索、打开规则、自动合并、Blue 或建立项目管理系统。

## Decisions

1. 保留外层分组卡片及顺序，组内改用自适应网格，块使用 `aspect-ratio: 1`，桌面与窄屏自动换列。名称居中，长名称允许换行并适当截断，悬停/辅助名称保留完整标题；可见内容不展示 URL。
2. 用户已确认整块淡雅浅色与细边框，并追加低饱和偏好。主题色低比例混入现有表面色，正文沿用主题文字色，避免鲜艳高对比色块；保留清晰的悬停与键盘焦点。
3. 颜色唯一输入为页面标题经 Unicode NFC、首尾去空格、统一小写后的名称。使用确定性字符串散列生成数值色相，配合统一低饱和样式；同名不受 URL、分组、排序或刷新影响，不持久化配色、不按别名或域名推断。同色只是辅助，仍显示名称，不承诺不同名称绝无近似色。
4. 沿用现有按钮、映射 ID、事件代理和精确 URL 服务。点击复用已打开页，右键菜单仍支持副本；打开状态改成角落轻量标记，完整状态由悬停和辅助名称提供，不能把查询失败当成未打开。
5. 复用现有转义函数；名称不直接进入 CSS，只输出经过数值计算的色相。仅调整现有渲染/样式及对应测试，不新增依赖、权限、模块或字段。

## Risks / Trade-offs

- 色相相近、色觉差异 → 颜色不替代名称，验证用户示例的辨识度和文字对比度。
- 长名称或窄屏拥挤 → 实测长中文/英文标题和移动布局，保持方形与可操作焦点。
- 外观变化影响旧事件命中 → 保留原映射属性，回归精确复用、右键副本与隐私模式。

## Migration Plan

新功能基于已合并的 `main` 在 `yzh/feat/shortcut-project-tiles` 开发。用户确认设计后实现并验证，再同步原加载目录；不重载用户浏览器，不把未验证的新界面合入 `main`。旧映射和备份无需迁移。
