## Context

Xiaoyu 已在精确切换并关闭重复新页后发送本地系统通知。用户确认改为 Chrome 工具栏原生弹层，不向目标网页注入内容。

## Goals / Non-Goals

- 只更换 Xiaoyu 成功反馈；保留自动复用开关、精确 URL 匹配、转发判断和关闭复核。
- Blue、工具栏点击打开工具、浏览器徽章计数和侧栏入口不变。

## Decisions

- 关页成功后仅为目标标签临时设置弹层，在其窗口调用 `chrome.action.openPopup`，然后恢复原工具栏映射。隔离 Chrome 已证实恢复映射不会关闭当前弹层。
- 弹层只显示双语固定成功文案，不传入网页数据，5 秒后自行关闭。
- 删除 Xiaoyu 不再使用的系统通知权限；保留原开关值。没有弹层接口时不开启自动复用，并在设置里提示。
- 不采用网页内浮层（需要网站访问）或持续替换工具栏默认弹层（会改变原点击入口）。

## Risks / Trade-offs

- Chrome 可能因为窗口失焦等拒绝弹层。若重复页已关闭，则记录反馈失败并恢复映射，不重试、不改用系统通知。
