## Why

用户希望重复打开 Xiaoyu 仪表盘时无需每次手动点击“只保留一个”，同时能够自行开关自动行为。自动关闭标签有副作用，必须保持默认兼容并集中协调，避免多页面互相关闭。

## What Changes

- 在“设置 → 标签页”增加“自动合并 Xiaoyu 页面”开关，默认关闭，长期本地保存；开启后从下一次打开仪表盘起执行。
- 关闭时保持既有重复提示和手动清理；开启时由后台保留最新创建的可处理仪表盘，自动关闭其他未置顶的 Xiaoyu 页面。
- 只处理同一 profile 的非隐身普通窗口和经过确认的本扩展仪表盘；不处理网页、Tools、Side Panel、其他扩展或 Blue。
- 删除前核实目标与保留页状态；失败停止或保留单项并明确反馈，不虚报成功。不增加权限。

## Capabilities

### New Capabilities

- `dashboard-singleton`: 可关闭的仪表盘自动合并设置、后台协调及删除保护。

### Modified Capabilities

无。既有网页精确 URL 防重功能与本设置相互独立。

## Impact

影响 Xiaoyu 后台、新增仪表盘合并服务与设置模块、仪表盘初始化/重复提示、打包清单及测试文档。保留全部存储键和权限，Blue 不变；只在隔离 Chrome 中操作测试标签。
