## MODIFIED Requirements

### Requirement: 在首次前台加载中按完整 URL 匹配

扩展 SHALL 只检查有创建资格的前台新标签的首次 HTTP(S) 加载。Blue 只接受从明确空白或新标签页起步的新标签；Xiaoyu 也接受 Chrome 在创建时提供有效来源标签 ID 且尚无已提交或挂起地址的前台新标签。在同一浏览器个人资料的非隐身普通窗口中，与已提交的完整网址精确比较，不删改协议、路径、查询参数或片段。

#### Scenario: 另一个窗口中有完整相同网址

- **WHEN** 已开启功能的用户在符合条件的前台新标签中首次加载一个网址，另一普通窗口已有完全相同的网页标签
- **THEN** 扩展 SHALL 选择该已有标签进行复用，不重新导航其页面

#### Scenario: 网页链接打开 Xiaoyu 前台新标签

- **WHEN** Xiaoyu 自动复用已开启，网页链接打开有创建资格的前台新标签，首次加载的完整网址与已有合格标签相同
- **THEN** Xiaoyu SHALL 按现有切换、复核、关闭及通知流程复用该已有标签

#### Scenario: 网址有差异或没有符合条件的目标

- **WHEN** 仅域名相同，或协议、路径、查询参数值、参数顺序、片段之一不同，或已有标签不满足复用条件
- **THEN** 扩展 SHALL 让新页正常加载，不切换到其它页面或关闭新页

#### Scenario: 不安全或无法确认的来源

- **WHEN** 浏览器事件不能确认新标签的创建资格，来源是无法识别的直开网址、已经在用的标签、刷新、后台打开、隐身、内部页面、启动或插件会话恢复，或新页已置顶、分组或超时
- **THEN** 扩展 MUST NOT 自动关闭该标签
