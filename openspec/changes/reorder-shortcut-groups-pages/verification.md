# 快捷分组与页面排序验证

日期：2026-11-24。

## 实现范围与契约

- 分组标题和每个页面左侧独立「⠿」柄，支持原生鼠标拖拽及 Alt/Option+上下键。多列卡片按左右半区、单列和页面按上下半区投放，并显示落点标记。
- 只改本地映射数组顺序，不修改分组归属、完整 URL、ID、标题、别名或颜色；没有新存储键、模块、依赖或权限，不移动、关闭或打开真实标签。
- 分组和页面排序共用既有写锁并重读最新数组；无效/已移除源与目标、跨组页面和未知位置拒绝写入，同位置无额外写入。保存成功才重绘，失败保留旧 DOM 顺序并提示。
- 拖拽/持久化期间延后卡片重绘，结束后补刷新；键盘排序保留同一柄焦点，Esc 取消未提交拖动而不触发隐私屏，视图切换及隐私模式清理临时状态。
- 快捷页、管理、搜索候选和原格式备份共用数组顺序，重命名与备份导入不丢顺序。
