## Why

用户已建立多个内网入口映射，接下来需要降低收录成本、避免搜索入口重复开页，并能以分组卡片直接访问常用页面。用户已明确要求同时实现快捷收录、已打开状态、多别名、本地备份和新的主页面入口。

## What Changes

- 一级导航变为“域名 / 工作 / 窗口 / 快捷”，快捷页按已有映射分组展示页面名称。
- 搜索结果与快捷卡片显示已打开及窗口信息，默认严格复用完整 URL 相同的页面；右键菜单及 Shift+Enter 明确新开副本，不关闭已有标签。
- 标签行增加快捷收录入口，自动填写当前页面标题与 URL。
- 映射支持多个别名，兼容没有 aliases 字段的现有数据。
- 支持本地 JSON 导出、导入预览及确认合并；不覆盖既有标题、分组或 URL，仅为重复映射合并新增别名。

## Capabilities

### New Capabilities

- `shortcut-library`: 分组入口卡片、快捷收录及安全的本地备份导入。

### Modified Capabilities

- `keyword-page-search`: 别名匹配、已打开状态、完整 URL 复用与显式副本。
- `organization-views`: 在原有三个一级入口之后增加“快捷”。

## Impact

只影响 Xiaoyu 的映射服务、独立打开服务、映射 UI、仪表盘导航及相应测试和文档。保留原数据键、过滤框语义和自动防重规则，不改 Blue，不增加权限或依赖，不 commit/push 或发布。
